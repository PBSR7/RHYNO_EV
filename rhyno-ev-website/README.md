# Rhyno EV Website

## Overview

This project is a React-based website for Rhyno EV, featuring an elegant, minimalistic design to showcase electric scooters. The website includes various pages such as Home, Product Pages, Compare All, Pre-book, About Us, Contact Us, and Rentals.
